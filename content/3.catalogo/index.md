## Qué es

Lo que la tienda vende: productos, variantes, categorías y marcas. El catálogo es dueño de las descripciones y de los precios de venta. No tiene un modelo de stock propio.

::note
Este dominio se está pasando a esta documentación. Mientras tanto, el detalle sigue en los README del código enlazados abajo.
::
